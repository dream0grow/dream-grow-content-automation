## 📋 상세 — 2026-08-17 09:40

## 회고 요약
thread/reels/newsletter/blog 네 채널 모두 동일하게 문장 어미 반복, 생각 표현 따옴표 오용, SNS식 감정 남발을 반복 수정하고 있어 규칙화 시점이다. 교실 에피소드 3단 구조(학년/시기-행동-결과)와 익명화된 인용 최소화는 채널 불문 공통 선호로 확인됐다. 단, 수치화된 규칙(톤 비율·섹션 수·훅 길이)은 실제 발행 성과 데이터 없이 팀 학습 요약만으로 도출돼 그대로 프롬프트에 강제하기엔 근거가 얕다.

## 제안 지침 (승인 시 모든 에이전트 프롬프트에 반영)
- 한 단락 안에서 동일한 문장 종결 어미(~습니다/~해요 등)를 3회 이상 연속 반복하지 않는다
- 인물의 생각·속마음은 작은따옴표(' ')로, 실제 대화(교실 에피소드 대사)만 큰따옴표(" ")로 표기한다
- 현장 사례를 쓸 때는 '학년/시기 - 행동(대화) - 결과' 3단 구조로 제시하고, 등장 인물·학교는 절대규칙 5에 따라 반드시 익명화한다
- 이론·개념을 인용할 때는 출처가 확인된 것에 한해 최소한으로(글당 1회 이하) 쓰고, 절대규칙 4(출처 없는 통계·연구 인용 금지)가 우선한다
- 'ㄷㄷ', 'ㅠㅜ', '!!' 같은 SNS식 감정 기호·인터넷 표현을 쓰지 않는다 — 절대규칙 6(이모지 금지)의 연장선으로 감정은 문장 리듬과 구체적 사례로 전달한다

## 사람 판단 필요 (기존 지침과 모순)
- 팀 학습 데이터의 '톤 40/35/25 비율', '5-9 섹션 강제', '훅 200자 제한' 같은 수치 규칙은 실제 발행 성과(A/B) 데이터 없이 요약만으로 도출됐다 — 프롬프트에 강제 규칙으로 넣을지 사람 판단 필요
- Reels 학습 데이터가 제안한 '에너지 표현(!!, 진짜 진짜 등) 제한적 허용'은 절대규칙 6(이모지·과잉 감정 표현 금지)과 상충할 수 있어 적용 보류, 사람 확인 필요
- '학술 인용 1개 허용' 방향이 절대규칙 4(출처 없는 통계·연구 인용 금지)와 정확히 어떻게 공존할지 — 출처 검증 가능한 인용만 허용할지 아예 인용 자체를 배제할지 사람이 결정해야 함

## 다음 실험 제안
- 문장 종결 어미 다양화 규칙 적용 전/후로 동일 주제 스레드 2편을 만들어 수정 횟수 비교
- 교실 에피소드 3단 구조(학년/시기-행동-결과) 명시 적용 버전과 자유 서술 버전을 뉴스레터 1편씩 발행해 반응 비교
- 인용 완전 배제 버전 vs 검증된 출처 1개 허용 버전을 블로그에서 나눠 발행해 신뢰도·수정 요청 빈도 비교
- 실제 발행 성과 데이터(좋아요·클릭·구독 전환)를 채널별로 수집할 파이프라인을 먼저 마련해 다음 회고부터 수치 규칙의 근거로 사용

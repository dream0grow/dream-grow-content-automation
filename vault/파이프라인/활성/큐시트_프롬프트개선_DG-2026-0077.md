## 📋 상세 — 2026-09-07 10:51

## 회고 요약
Honcho 교정 데이터는 이모지·인터넷 슬랭 배제, 교실 3단 에피소드(학년/시기-행동-결과) 구조, 부모의 실제 언어를 훅에 살리는 패턴을 일관되게 지지하며 이는 절대규칙(이모지 금지·익명화·과장 금지)과 잘 맞는다. 다만 이 학습 데이터에 드림그로우에 없는 'Book 채널' 비교와 'SNS는 이모지 제한적 허용' 같은 서술이 섞여 있어 다른 페르소나 데이터와 혼입됐을 가능성이 크다. 5-9섹션·200자 훅·40/35 톤비율 같은 수치 공식화 제안은 절대규칙(공포·죄책감 유발 금지, 이모지 금지)과 휴머나이즈(AI 티 제거) 목표 모두와 충돌 소지가 있어 그대로 반영하면 위험하다.

## 제안 지침 (승인 시 모든 에이전트 프롬프트에 반영)
- 교실 사례는 반드시 '학년/시기(범위로 뭉뚱그림) - 아이의 행동 - 결과' 3단 구조로만 제시하고, 특정 인물·학교가 특정되지 않도록 세부 정보를 더 뭉갠다(절대규칙5 강화).
- 발달심리 이론을 언급할 때는 이론가 이름과 개념명(예: 드웨크 마인드셋, 피아제 도덕성 발달 단계)까지만 쓰고, 구체적 수치·통계·연구 결과는 절대 덧붙이지 않는다(절대규칙4 재확인 문구를 WRITER 프롬프트에 명시).
- 부모의 실제 구어체 고민 문장을 리서치 단계에서 브리프로 그대로 넘겨 훅 첫 줄에 직접 반영하도록 브리프 프롬프트에 명시한다(현재 발행 사례들에서 잘 작동 중인 패턴 강화).
- CRITIC 프롬프트의 'AI 티' 체크리스트에 'Not A, but B' 같은 정형화된 대조 구문과 지나치게 규칙적인 섹션 개수·문장 리듬 반복을 감지 항목으로 추가한다.
- '경고'·'긴급'류 톤 지시는 프롬프트에 넣지 않는다 — 정보 전달은 담담하게, 감정적 긴장은 교실 에피소드의 구체성으로만 만든다는 문구를 WRITER 톤 가이드에 명시한다.

## 사람 판단 필요 (기존 지침과 모순)
- 팀 학습 데이터의 'SNS 채널은 이모지 제한적 허용'은 절대규칙6(이모지 사용 금지, 예외 없음)과 정면 충돌 — 반영 금지, 사람 확인 필요.
- '40% 사실/경고 톤 + 35% 공감' 같은 어조 비중 공식은 절대규칙1(죄책감·공포 유발 금지)과 충돌할 수 있어 그대로 도입할지 사람 판단이 필요하다.
- 5-9섹션/200자 훅/13개 훅 패턴 매핑 같은 수치화된 형식 공식은 브랜드가 지향하는 '휴머나이즈(AI 티 제거)' 원칙과 상충 — 형식이 예측 가능해질수록 오히려 AI 느낌을 줄 위험이 있어 반영 여부는 사람이 결정해야 한다.
- 네 채널(thread/reels/newsletter/blog) 요약 모두에 드림그로우 실제 채널에는 없는 'Book 채널' 비교가 섞여 있음 — Honcho 학습 데이터가 다른 브랜드/페르소나와 혼입됐을 가능성이 있어, 이 데이터 전체를 프롬프트에 반영하기 전에 데이터 출처 확인이 필요하다.

## 다음 실험 제안
- 부모의 실제 언어 문장을 훅 1줄에 그대로 쓰는 버전과 재가공한 버전을 다음 주 카드 2~3건에 나눠 적용해 저장·공유 반응 비교.
- 교실 3단 에피소드 구조를 넣은 카드와 안 넣은 카드의 반응 차이를 비교해 이 구조의 실제 효과를 검증.
- 현재 회고 데이터에 좋아요·저장·공유 등 실제 참여 지표가 전혀 없어 패턴-성과 상관관계를 판단할 수 없음 — 카드 frontmatter나 발행 기록에 참여 지표를 남기도록 파이프라인을 보완하는 실험을 우선 진행.

## 📋 상세 — 2026-09-14 11:20

## 회고 요약
채널 전반에서 문장 끝맺음·인용부호·훅 길이 관련 수정이 2회 이상 반복돼 규칙 승격 대상이 뚜렷하다.
발행 성과가 좋은 초안들은 부모의 실제 말투를 그대로 인용하고, 위협적 전개 뒤 곧바로 안심시키는 문장을 배치하는 공통점을 보인다.
Honcho 학습 데이터의 톤 비율·이모지 허용 제안 중 일부는 절대규칙 및 실제 발행 스타일과 어긋나 채택 전 확인이 필요하다.

## 제안 지침 (승인 시 모든 에이전트 프롬프트에 반영)
- 생각·감정을 표현할 때는 큰따옴표 대신 작은따옴표를 쓴다 (thread/newsletter/blog 채널에서 반복 수정된 항목)
- 도입부(훅)는 부모가 실제로 쓸 법한 말투의 문장으로 시작하고 200자를 넘기지 않는다
- 본문 전개에서 걱정을 키우는 문장을 쓴 뒤에는 반드시 뒤이어 안심시키는 짧은 문장을 붙여, 절대규칙 1(죄책감·공포 유발 금지)을 구조적으로 지킨다
- 발달심리·교육학 이론을 언급할 때는 피아제·비고츠키 등 이름이 검증 가능한 고전 이론에 한해 이름만 밝히고, 구체적 수치나 통계는 출처 없이 붙이지 않는다
- 동일한 수정 지시가 회고에서 2회 이상 반복 확인되면 다음 프롬프트 갱신 때 바로 규칙으로 반영한다

## 사람 판단 필요 (기존 지침과 모순)
- Honcho 학습 데이터는 'SNS 채널에 한해 이모지 일부 허용'을 제안하지만 절대규칙 6은 예외 없이 이모지를 금지한다 — 반영 여부가 아니라 학습 데이터 출처(다른 프로젝트 혼입 가능성)를 먼저 확인해야 함
- '습니다체 40% / 해요체 35%' 톤 비율 규칙이 실제 최근 발행 스레드(DG-2026-0065 등)의 구어체·반말 위주 문체와 맞지 않는다 — 비율을 프롬프트에 강제할지, 실측 발행 스타일을 기준으로 다시 잡을지 판단 필요
- '5-9섹션 + cliffhanger' 구조는 학습 데이터상 book(장문) 채널 기준으로 보이는데, thread 형식(500자 단위 분할 포스트)에 그대로 적용 가능한지 채널별 검증이 필요

## 다음 실험 제안
- 도입부를 부모의 실제 말투 인용으로 시작하는 버전과 기존 훅 버전을 비교
- 위협 문장 뒤 안심 문장 배치 위치(중간 vs 마지막 섹션)를 바꿔 반응 비교
- 습니다체 비중을 낮추고 해요체 위주로 통일한 스레드 버전 실험
- 이론 이름을 명시한 버전과 이름 없이 '한 심리학 이론에 따르면'으로 익명화한 버전 비교

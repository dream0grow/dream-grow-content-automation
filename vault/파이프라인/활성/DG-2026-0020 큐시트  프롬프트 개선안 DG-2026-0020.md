## 📋 상세 — 2026-07-27 10:58

## 회고 요약
네 채널(스레드/릴스/뉴스레터/블로그) 모두에서 과도하게 격식적인 종결어미·따옴표 인용 오류·이모지 및 인터넷 감정 기호 남용이 반복 수정되어 규칙화 대상으로 확정됐다. 선호 방향은 형식 순수주의(이모지·해시태그 금지)와 5~9개 섹션 구조, 3부분 교실 에피소드(학년/시점-행동-결과, 반드시 익명화) 중심 근거 제시다. SNS 채널의 감정 기호 허용 여부에 학습 데이터 내 상반된 언급이 있어 사람 판단이 필요하고, 최근 발행 성과 데이터가 없어 어떤 패턴이 실제로 효과적인지는 아직 검증되지 않았다.

## 제안 지침 (승인 시 모든 에이전트 프롬프트에 반영)
- 문장 종결에서 '~습니까/~하십시오' 같은 과도하게 격식적이거나 명령조인 표현을 쓰지 말고, '~습니다'와 '~해요'를 자연스럽게 섞어 마무리할 것
- 생각이나 회상을 표기할 때 큰따옴표(쌍따옴표)로 인용하듯 쓰지 말고 서술형이나 홑따옴표로 표기할 것
- 이모지·해시태그·인터넷 감정 기호(ㄷㄷ, ㅠㅜ 등)는 모든 채널에서 사용하지 않을 것(절대규칙 6번과 일치)
- 도입부(훅)는 200자 이내로 작성하고, 본문은 5~9개 섹션과 자연스러운 전환으로 구성하며, 근거는 출처 불명 통계보다 3부분 교실 에피소드(학년/시점-행동-결과, 반드시 익명화)를 우선할 것
- 동일한 수정이 2회 이상 반복 발견되면 다음 회고에서 즉시 프롬프트 규칙으로 승격하고, 중복되는 기존 규칙은 병합해 정리할 것

## 사람 판단 필요 (기존 지침과 모순)
- SNS 채널(릴스/스레드)에서 감정 기호를 제한적으로 허용할지 여부에 대해 학습 데이터 내 상반된 언급이 있음 — 이모지 사용 금지라는 절대규칙과 정면으로 충돌할 수 있어 사람 판단 필요
- 종결어미 비율(격식형/친근형 배분)을 프롬프트에 수치로 고정할지 여부 — 브랜드 보이스의 자연스러움과 과도한 수치화 사이에서 사람 판단 필요
- 최근 발행 콘텐츠 실제 반응 데이터가 없는 상태에서 '효과적인 공식'으로 제시된 섹션 수·훅 길이 등 수치 규칙을 확정해도 되는지 — 검증되지 않은 채 규칙으로 굳히는 것은 신중해야 함

## 다음 실험 제안
- 다음 주 스레드 카드 중 일부에 종결어미 격식/친근 배분을 명시적으로 지정해 반응 차이를 비교한다
- 훅 200자 제한과 3부분 교실 에피소드 형식을 브리프 단계에 명시적으로 요구하도록 prompts.py를 수정한 뒤 검수 통과율 변화를 관찰한다
- 발행 후 반응(조회·클릭 등) 수집 체계를 self_improve.py 회고 루프에 연결해, 다음 회고부터는 팀 학습 데이터뿐 아니라 실제 성과 데이터도 함께 분석한다

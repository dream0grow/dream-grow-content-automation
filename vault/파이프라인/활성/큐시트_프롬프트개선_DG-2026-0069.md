## 📋 상세 — 2026-08-31 11:18

## 회고 요약
채널 전반에서 반복 수정된 핵심은 문장 종결 어미 순화(~습니까/~하십시오 제거, ~ㅂ니다·~해요 혼합)와 따옴표 통일(대사=큰따옴표, 생각=작은따옴표), SNS식 감정기호 배제로 수렴했다. Hook 13패턴·5-9섹션+클리프행어·3부 교실 에피소드(학년/시기→행동→결과)가 채널 공통 포뮬러로 반복 확인됐고, 동일 수정 2회 반복 시 즉시 규칙화하는 원칙이 전 채널에서 일관 적용됐다. 다만 '이론명 익명화' 원칙과 실제 최근 발행 초안(DG-2026-0065)이 '피아제'를 실명 인용한 점, 채널별 감정표현 허용 범위가 관찰마다 엇갈리는 점은 조정이 필요하다.

## 제안 지침 (승인 시 모든 에이전트 프롬프트에 반영)
- 문장 종결: ~습니까/~하십시오 사용 금지. ~ㅂ니다/습니다(약 40%)와 ~해요(약 35%) 혼합을 기본으로 하고 과도한 격식체 남발을 피한다
- 따옴표 규칙 통일: 인물의 말(대사)은 큰따옴표("), 생각·강조는 작은따옴표(')로 일관되게 사용한다
- 근거 제시는 3부 교실 에피소드(학년/시기 → 행동/대화 → 결과)를 1순위 권위로 쓰고, 출처가 불분명한 학술 이론은 실명 대신 '한 심리학자', '발달심리학에서' 식으로 일반화한다
- Hook은 200자 이내로 주제 성격(경고형/실용형/공감형 등)에 맞춰 톤을 매칭하고, 본문은 5~9개 섹션으로 나눠 각 섹션 끝에 다음 내용을 궁금하게 만드는 여운을 남긴다
- 이모지·해시태그·인터넷 감정기호(ㄷㄷ, ㅠㅜ 등)는 전 채널에서 배제하고, 감정 전달은 문장 리듬과 구체적 에피소드로 대체한다

## 사람 판단 필요 (기존 지침과 모순)
- '이론명 익명화' 원칙과 실제 발행 초안(DG-2026-0065)이 '피아제'를 실명으로 명시 인용한 점이 상충 — 실명 인용을 허용할지 사람 판단 필요
- SNS 채널(스레드/릴스)의 감정 표현 허용 수준이 관찰마다 다름(완전 배제 vs 상황별 허용) — 브랜드 보이스 '따뜻하지만 명확하게'와의 균형은 사람이 정해야 함
- 40%/35% 엔딩 비율이 정량 규칙으로 못 박을 만큼 안정적인지 불확실 — 실제 발행 스레드(DG-2026-0065)는 캐주얼한 대화체 비중이 더 높아 괴리 가능성

## 다음 실험 제안
- 스레드 1건을 이론 실명 인용판과 일반화 인용판(A/B)으로 나눠 반응 비교
- Hook 13패턴 중 주제별 매칭표를 prompts.py에 명시 적용해 저장·공유율 변화 확인
- 5-9섹션+클리프행어 구조 적용 전후로 완독·댓글 반응 비교

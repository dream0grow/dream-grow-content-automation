# 핵심 주장 (이 주제 영상들의 공통 주장)
- 고전은 효과가 크다. 단 완역본을 그냥 들이밀면 실패한다 — 단편·발췌·"한 줄 고전"부터.
- 재미가 먼저다. 고학년 추천 영상들조차 "책이 재미없다면", "재미있는 소설 많이 읽기"를 전면에 건다.
- 읽기 자체보다 '읽고 나눈 대화'가 본체다 (질문·이야기 나누기·필사).
- 천천히·반복해서 읽으면 어려운 책도 만만해진다 (EBS 슬로리딩 실험).

# 꼭 남겨야 할 예시
- 사례 1: EBS 슬로리딩 — 국어 교과서 대신 『그 많던 싱아는 누가 다 먹었을까』 한 권을 한 학기.
  산만하던 아이가 몰입하고, 발표를 무서워하던 아이가 토론을 주도하게 됨.
- 사례 2: 흔한 남매 22권을 하루 세 번 읽는 아이 — "엄마, 책은 한 번만 읽는 게 아니야.
  한 2주 뒤에 다시 보면 새로운 게 보인다니까?" (재미가 반복 독서를 스스로 가르친 사례)
- 비유: 만화책 읽는 방식(재미→반복→몰입)이야말로 고전에 이식할 읽기 기술
- 숫자: "책을 읽지 않는다"는 초등생 4학년 23.9% → 6학년 33.5% (한국교육과정평가원)
- 비교: 강제 없는 재미 독서(크라센 FVR)가 전통 지도보다 문법·어휘·성적에서 앞섬

# 댓글에서 드러난 진짜 관심사
- 가장 많이 나온 질문: "만화(학습만화)만 보는데 괜찮을까요?" / "고전·필독서, 몇 학년부터 뭘 읽혀야 하나요?"
- 가장 많이 나온 불안: "읽어도 남는 게 없어요(줄거리를 말 못해요)" +
  "억지로 시켰다가 책 자체를 싫어하게 될까 봐" — 실제로 "슬로리딩을 할수록 책을 재미없어해요" 사례 존재
- 가장 많이 나온 오해: ① 학습만화는 독서가 아니다·금지해야 한다
  ② 고전은 완역본을 처음부터 끝까지 정독시켜야 효과가 있다 ③ 필독서 목록은 전부 읽혀야 한다
- 가장 많이 나온 기대: 문해력·어휘력·국어 성적, "생각하는 힘", 대화가 되는 아이.
  성공담의 공통점은 전부 '아이가 재미를 느낀 순간' 이후에 왔다.

# 타겟 언어 수집
- 그대로 저장할 표현: "우리 애는 학습만화만 봐요" / "줄글 책은 안 읽어요" / "100권 읽어도 소용없대요" /
  "우리집도 학습만화 금지야" / "흔한 남매만 읽어요" / "다독에 집착했어요"
- 제목에 쓸 수 있는 표현: "만화로만 된 책만 보려고 해요" / "책이랑 친해지기"
- 도입부에 쓸 수 있는 표현: "좋아서 읽던 책이 해야 해서 읽는 책으로 바뀌었어요" /
  "독서가 또 하나의 숙제가 됐어요"
- 본문에서 반박해야 할 표현: "학습만화 금지" / "정독 좀 시켜주세요" / "필독서 하나도 빠짐없이"

# 놓치면 안 되는 포인트
- 부모 최대 공포는 돈이 아니라 역효과 — "시켰다가 책을 아예 싫어하게 되는 것". 이걸 정면으로 다뤄야 한다.
- 만화책을 적이 아니라 스승으로 뒤집는 관점이 이 원고의 반전 — 부모가 금지하는 그 읽기 방식이 정답.
- 고전 진입 순서(쉬운 고전·선정적이지 않은 고전·소설 중심)는 실제 검색어 수요("몇 학년부터 뭘")와 정확히 겹친다.
- 못 찾은 것: '만화→줄글 전환 성공률' 직접 통계, 고전 독서↔성적 인과의 대규모 통제 연구 (원고에서 단정 금지).

# 썸네일 참조 이미지 (실제 책 표지 등)

키워드별 폴더에 이미지를 넣으면, 확정 렌더(색칠 완료 행)가 그 이미지를 **참조**해
장면을 생성한다 — 예: 실제 데미안(민음사) 표지를 든 아이.

- 폴더 이름: 시트 L열 키워드에서 공백·특수문자를 뺀 것 (예: `초등 고전 독서` → `초등고전독서/`)
- 형식: jpg/png/webp, 폴더당 최대 4장 사용
- 올리는 법: GitHub 웹에서 이 폴더 열기 → Add file → Upload files (드래그 앤 드롭)
- OpenAI(gpt-image-1 edits) 또는 Google(Gemini 이미지 입력) 키가 있어야 동작.
  참조 편집이 실패하면 일반 생성으로 자동 폴백.

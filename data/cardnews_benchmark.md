# 카드뉴스 벤치마킹 (갱신: 2026-09-15 08:55 KST, 신뢰도: low)

## 지금 뜨는 흐름
- 표지에 텍스트 1~2줄만 크게 넣고 나머지는 사진/여백으로 비우는 미니멀 카드뉴스
- 손글씨체·다이어리체 폰트로 '진짜 사람이 쓴 메모' 느낌을 내는 포맷
- 본문 없이 캡션에 전체 서사를 담고 카드뉴스는 요약 슬라이드로만 쓰는 구성
- 전문가(교사·의사 등) 신분을 표지에 명시해 신뢰도를 앞세우는 포맷
- 체크리스트/자가진단형('나만 이런가요' 식 자기 발견) 카드뉴스
- before-after 대비 구조(예전엔 이렇게 했는데 → 이렇게 바꿨더니)
- 인용구 한 문장을 배경 사진 위에 크게 얹는 '명언 카드' 스타일
- 마지막 장에 '저장해두고 다시 보세요' 식 저장 유도 문구를 명시적으로 배치
## 후킹(표지) 패턴
- 질문형: '혹시 우리 아이도 그런가요?' 식으로 부모의 관찰 경험을 되묻는 문장
- 반전 예고형: '이거 하지 마세요' 처럼 통념을 먼저 부정하고 이유는 다음 장으로 미루는 문장
- 1인칭 경험 고백형: '저도 교실에서 이런 아이를 만난 적이 있습니다' 식 현장 경험 공개
- 숫자 나열형: '아이가 이런 말 3가지를 한다면' 처럼 구체적 개수를 제시해 스크롤을 유도하는 문장
- 공감 선언형: '~한 부모님, 당신 잘못이 아닙니다' 식으로 안심을 먼저 주는 문장
- 대비형: '흔한 조언 vs 실제로 통하는 방법' 처럼 기존 정보와의 차이를 표지에서 예고
## 전개 구조 패턴
- 표지(문제 제기) → 공감(부모 상황 묘사) → 원인/맥락 설명 → 실천 단계 1~3 → 요약+저장 유도, 총 6~8장 구성
- 표지 → 통념 제시 → 반전(교사·전문가 관점) → 이유 → 오늘부터 할 수 있는 행동 1가지로 마무리하는 짧은 구성(5장 내외)
- 체크리스트형: 표지 질문 → 항목 4~6개를 한 장씩 보여주고 마지막 장에 해석/다음 행동 제시
## 시각 요소 패턴
- 실사 인물 사진(스톡보다 자연광·생활 밀착 컷) 위에 굵은 고딕/손글씨 오버레이
- 여백을 넉넉히 둔 1~2줄 카피 + 저채도 배경색(베이지·연회색 계열)으로 피로감 낮추기
- 슬라이드마다 같은 색상 팔레트·같은 폰트 크기 위계를 유지해 시리즈 느낌 주기
- 표 형태 대신 아이콘+짧은 문구 카드로 정보를 나누어 스캔하기 쉽게 구성
- 마지막 장은 텍스트를 줄이고 브랜드 로고/저장 유도 문구만 배치해 여백으로 마무리
## 캡션·CTA 패턴
- 캡션 첫 줄에 카드뉴스 핵심 메시지를 한 번 더 요약해 피드에서도 내용이 보이게 하기
- '저장해두고 힘들 때 다시 보세요' 식 저장 유도 문구를 캡션 말미에 배치
- 댓글 유도형 질문('우리 아이는 어떤가요? 댓글로 알려주세요')으로 참여 늘리기
- 관련 이전 게시물이나 뉴스레터/추가 자료 링크를 캡션에 안내
## 피할 요소
- '이렇게 안 하면 늦습니다' 류의 불안·공포 조장형 문구 (드림그로우 절대규칙 위반이기도 함)
- 출처 없는 '전문가 90%가 말하는', '연구 결과' 식 수치 인용 남발
- 지나치게 많은 이모지·형광색 강조로 신뢰도를 떨어뜨리는 디자인
- 표지와 본문 내용이 어긋나는 낚시성 후킹(클릭 후 이탈률 상승)
- 한 장에 텍스트를 과도하게 채워 스캔이 어려운 레이아웃

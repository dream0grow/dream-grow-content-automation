# 유튜브 썸네일 벤치마킹 패턴 라이브러리 + 6단계 방법론

> 출처: 사용자의 벤치마킹 구글 시트 2개(분석 시트 + 썸네일 문구 구조 연습 시트, 2024.6 ~ 2026.8)를
> 코드 저장소로 이관한 것. `orchestrator/thumbnail.py`가 프롬프트에 주입한다.
> 시트에 새 분석이 쌓이면 이 파일에 같은 형식으로 추가한다.

## 0. 대원칙

- **벤치마킹 썸네일에서 출발한다.** 패턴을 임의로 고르는 게 아니라, 실제로 터진 썸네일 하나를
  놓고 그것의 감정·구조를 분해한 뒤 내 주제를 대입한다.
- **문구와 제목은 세트다.** 썸네일 문구 구조와 영상 제목 구조를 함께 분해하고 함께 디벨롭한다.
  (제목은 보통 문구가 가린 정보를 괄호로 보강하거나, 문구의 감정을 한 번 더 증폭한다.)
- **감정을 그대로 가져간다.** 벤치마크가 기대를 만들었으면 디벨롭도 기대를 증폭해야 한다.
  구조만 베끼고 감정이 바뀌면 실패다.

## 분석 1단계 — 썸네일을 보는 사람 분석 (상황 → 고민 → 욕구 → 계획)

| 항목 | 뜻 | 예시 (벤치마크: 영어공부) |
|---|---|---|
| 상황 | 시청자가 놓인 구체적 장면 | 영어 책 읽기·영어 공부를 잘하고 싶은 마음 |
| 고민 | 머릿속에 도는 질문 | 영어 책을 어떻게 하면 한글처럼 잘 읽을 수 있을까? 영어를 모국어처럼 능통하게 하려면? |
| 욕구 | 해결하고 싶은 핵심 바람 | 영어 실력 향상 |
| 계획 | 욕구를 풀려고 하려는 행동(검색) | 영어 책을 잘 읽는 방법을 알고 싶다 |

- 욕구는 "간단하게, 빨리, 돈 안 들이고, 부담 없이" 해결되길 바란다.
- 디벨롭할 때는 원 영상의 욕구 → 내 주제의 욕구로 매핑부터 한다.
  (연습 시트 실례: "스윙 잘해서 골프 잘하고 싶다" → "말 한마디 바꿔서 자존감 문제를 쉽게 해결하고 싶다")

## 분석 2단계 — 썸네일이 불러일으키는 감정 분석 (기대/의문/증거/공감, 10점 배분)

문구 + 그림(이미지)이 합쳐서 감정 10을 만든다고 보고, 어느 쪽이 어떤 감정을 몇 점 만드는지 배분한다.

- 예: "영어 문장 한글처럼 읽는 법" 썸네일 = **문구가 기대 9** (한글처럼 읽고 싶다는 마음을 만듦,
  제목을 읽고 기대감 증가) + **그림이 기대 1** (영어 책을 손가락으로 가리키며 읽는 모습).
- 다른 배분도 가능: 문구 기대 8 + 그림 공감 2 / 문구 공감 7 + 그림 기대 3 …
- 4감정의 정의:
  - **기대**: 이걸 보면 나도(우리 아이도) 될 것 같다 — 적은 투입으로 큰 결과 약속
  - **의문**: 이게 뭔데? — 정보를 가려('이것', 'OO', '딱 2가지') 궁금하게
  - **증거**: 믿을 만하다 — 전문가·경력·실물 결과(Before→After)·인터뷰 장면
  - **공감**: 맞아, 내 얘기잖아 — 일상 장면·속마음을 1인칭 대사로
- 그림 아이디어를 낼 때는 감정 카테고리를 붙여 여러 방향을 제시하고, 효과 없어 보이는 감정은
  이유와 함께 제외한다. (연습 시트 실례: "(증거) 비포→애프터 / (공감) 스트레스 상황 /
  (기대) 개선 방향 보여주기 / (의문은 효과적이지 않을 것 같음)")

## 분석 3단계 — 썸네일 문구 + 제목 세트 구조분석

문구와 제목을 (변수)로 분해한다. 형식: `문구 구조 (제목 구조)` + 주의할 점.

- 예: 문구 "영어 문장 한글처럼 읽는 법" / 제목 "이 방법으로 읽으니 영어 문장 다 뚫렸습니다."
  → 구조: **(내가 원하는 것 A)을 (평소에 쉽게 하는 것 B)처럼 하는 방법**
  (제목: "이 방법으로 하니 (내가 원하는 것 A)를 다 해결했습니다.")

## 분석 4단계 — 구조에 내 주제 대입 (문구 디벨롭)

1. 구조의 변수에 내 주제(키워드)를 대입한다. 어느 변수에 해당하는지 먼저 선언한다.
   (예: (내가 원하는 것 A) = 초등 고전 독서)
2. **2단계에서 확인한 감정을 증폭하는 방향**으로 문장을 만든다.
3. 한 구조당 변주를 5~10개 만든다 (연습 시트는 구조당 5~11개씩 만들었다).
   예: "초등 고전 독서를 만화책처럼 읽는 방법" / 제목 "이 방법으로 하니 초등 고전 독서, 완전 푹! 빠지게 만듭니다."
4. **이미지 디벨롭**: 원 썸네일 그림의 감정 점수를 확인하고, 그 감정을 더 높일 아이디어를 낸다.
   예: 그림 기대 1 → 유명 고전(데미안·싯다르타·인간관계론)을 들고 편안하게 읽는 아이 사진
   → "우리 아이도 이렇게 읽으면 좋겠다"는 기대 부여.

## 분석 5단계 — 다른 키워드(주제) 확장

내 채널 타겟(초등 학부모)이 **방법을 알기 원하는 것**을 리서치해서 같은 구조에 대입한다.
(방법을 원하는 것을 찾는 이유: 구조가 "(원하는 것 A)을 (쉬운 것 B)처럼 하는 방법"이기 때문 —
구조의 전제 조건에 맞는 키워드만 찾는다.)
이때도 2단계의 감정을 반드시 그대로 가져간다. 키워드마다 4단계를 반복한다.

## 분석 6단계 — 검증 (1단계로 되돌아가 확인)

만든 문구·제목이 그 키워드 시청자의 상황-고민-욕구-계획에 실제로 연결되는지 확인한다.
- 외부 리서치(Manus/유튜브 댓글/블로그/네이버 카페)로 "진짜 그것을 바라는 사람"이 있는지 확인.
- 상황/고민/욕구/계획 각각의 연결 강도와 욕구(해결하고 싶은 강도)를 점수로 매긴다.
- 리서치 근거 없이 모델 판단만으로 매긴 점수는 반드시 "모델 추정"으로 표기한다.
- (연습 시트의 실전 검증 예: "대화 잘하는" 1회 검색 → 전체 조회수 7,600만, 굿&그레이트 13개,
  조회수 중앙값 1만/구독자 중앙값 3천 → 충분히 좋은 주제 + 상위 영상 댓글 수집으로 욕구 확인)

## 구조 공식 라이브러리 (문구 구조 (제목 구조) + 주의할 점)

연습 시트에서 실측·검증된 공식. 디벨롭 실례는 연습 시트의 실제 결과물이다.

| # | 구조: 문구 (제목) | 주의할 점 / 실례 |
|---|---|---|
| 1 | (내가 원하는 것 A)을 (평소에 쉽게 하는 것 B)처럼 하는 방법 ("이 방법으로 하니 A를 다 해결했습니다.") | A는 시청자가 어렵다고 느끼는 것, B는 이미 쉽게 하는 것. 기대 증폭형 |
| 2 | 갑자기 (원하는 능력 A)를 잘하게 되는 사람들의 공통점 "이 1가지만 미친듯 해요." ((돈쓰는 B) 없이 돈 안쓰고 갑자기 A 급상승하는 사람들의 공통된 특징) | 돈 쓰지 않아도 빠르게 실력이 는다는 기대감 제공. 실례: "갑자기 말빨이 좋아지는 사람들의 공통점 (스피치 과외 없이…)" |
| 3 | 이것만 죽어라 외우세요. (의존하는 A) 없이 (원하는 능력 B)를 얻는 (반복하는 쉬운 C) | "이것만 하면 될 것 같은" 느낌. 실례: "이것만 죽어라 외우세요. 선천적 말빨 없이 대화의 신이 되는 대화 스킬 3가지" |
| 4 | (A의 원리/규칙) 이게 전부입니다. 제발 외우세요! (원하는 능력 A는 이 3가지가 핵심입니다. 비싼 수업 들어도 이걸 알려주는 사람은 없어요.) | 우리가 모르는 원리가 있는 것으로 기대감 제시 |
| 5 | 누구도 알려주지 않은 (시도하려는 A)의 비밀 | A는 위험·리스크가 커서 정보를 알아야 안심되는 것. 이 영상 보면 위험을 줄일 수 있다는 기대 |
| 6 | 모든 (결과 A) 문제는 (간단한 원인 B) 때문이다. (저의 A는 이걸 알기 전과 후로 모든 게 바뀌었습니다.) | A와 B는 실제 인과가 있어야 함. 원인을 알면 해결된다는 기대감. 실례: "모든 인간관계의 문제는 말 한마디 때문이다" |
| 7 | (일상적 상황 A)일 때 자꾸 (문제 B)가 발생해요. 이렇게 하면 안 생깁니다. (B가 자꾸 생기는 N가지 이유, 해결법까지) | 1인칭 대사로 공감 유발. 실례: "사람들 앞에서 자꾸 불편해져요. 이렇게 하면 편해집니다." |
| 8 | (능력이 적을 때 A) 이 2가지만 하면 (원하는 상황 B)이 됩니다 | B는 구체적·가시적으로. 실례: "우울할 때 이 2가지만 하면 8시간 숙면합니다" |
| 9 | (쉽게 행동하는 A) 이것만 바꾸면 (병원/학원 등 비싼 대안) 안 가도 됩니다 | 매일 하는 작은 행동으로 큰 문제를 해결한다는 기대감이 핵심 |
| 10 | (매일 하는 행동 A) 제발 이렇게 해보세요. A 문제 안 생기게 하는 법 (인생이 달라질 거예요) | A가 궁극적 욕구를 정말 해결해줘야 함 (쿠션→예뻐 보이고 싶다) |
| 11 | 딱 N시간만 연습해보세요. (얻고 싶은 능력 A) 제대로 배웁시다 | 빠른 시간 안에 정석대로, 완전히 얻을 수 있다고 느끼게 |
| 12 | (빠른 기간 A) 안에 (목표를 이룬 B)한 사람들이 의도적으로 쓰는 방법 | B는 시청자 욕구의 결에 맞는 사람이어야 함. 실례: "우울증 1년만에 극복한 사람들이…" |
| 13 | N일만에 (행동 A)해서 (거대한 B)를 얻었습니다 | 짧고 간단한 행동으로 거대한 결과 — 기대 증폭 |
| 14 | 딱 (시간)만에 (내용) 확인하는 법 | 실례: "딱 1초만에 대장암 확인하는 법" → "딱 5분만에 공부 잠재력 확인하는 법" |
| 15 | (문제 현상 A) 겪는 사람들이 자주 (하는 행동 B) | 실례: "자존감 낮은 사람들이 인스타그램에 자주 올리는 사진" |
| 16 | (일상에서 알아차리는 증상 A) 있다면 (큰 문제 B)가 이미 시작됐다 | 실례: "친구에게 이렇게 말하고 있다면 우울증은 이미 시작됐다" |
| 17 | (간단한 신호 A) 무시하면 (큰 문제 B)가 일어난다 | |
| 18 | (작은 행동/상식 A)보다 치명적, (큰 문제 B) 높이는 최악의 (원인 C) | 실례: "매운 음식보다 치명적 위암 발병 높이는 최악의 식습관" |
| 19 | (도구/개념 A와 B) 이 차이를 모르면 평생 손해입니다 | 실례: "칭찬과 격려, 이 차이를 모르면 평생 자존감이 낮습니다" |
| 20 | 이런 말을 하면 즉시 (행동 A)를 해라. 후회해도 늦는다 | |
| 21 | (전문가 A) N년차가 본 확 (부정적으로 변한 모습 B)한 사람들의 공통점 | 실례: "심리학자 10년차가 본 확 자존감 무너진 사람들의 공통점" |
| 22 | (특정 시점 A)부터 (문제 B)를 겪는 사람들의 공통점 (A부터 B를 겪는 이유! B 해결법) | |
| 23 | 나는 왜 이렇게 (문제 A)를 많이 경험할까? | 실례: "나는 왜 이렇게 가족들이 불편할까?" |
| 24 | (관찰되는 행동 A)하고 있다면 그냥 지나치지 마세요 (A의 숨은 의미와 심리) | |
| 25 | (특정인 A)가 가장 싫어하는 (사람/행동 B)는? | A는 문제 해결에 반드시 만나야 하는 사람 |
| 26 | (구체적 문제 갖고 있는 사람 A) 95%는 이걸 몰라서 그렇습니다 | |
| 27 | (쉬운 A)를 절대 '이렇게' (행동)하지 마세요! (결정적 문제 B) 생기고 (C) 생깁니다 | 결정적 문제는 신체 증상·돈 문제처럼 생존을 위협하는 것 |
| 28 | (대중적 해결책 A)를 당장 끊어야 하는 N가지 신호 (A의 부작용 신호) | A는 쉽게 얻는 해결책이면서 부작용이 걱정되는 것 |
| 29 | (하고 싶은 행동 A)를 하면 안 되는 사람 특징 (본인이 A를 잘할 수 있을지 판독해드립니다) | |
| 30 | 너무 (상대를 위하는 A)하면 반드시 망한다. (자기 이득 되는 C)하라 | 통념을 깨는 역발상. 관계 행동이어야 함 |
| 31 | (A 할수록) 망한다. '독이 되는' (사람 B) 압도적 1위 | 손실 회피 자극. 관계 행동이어야 함 |
| 32 | 왜 그때 (나쁜 A)에게 (표현 B)를 못했을까 | A는 관계적으로 나쁜 행동을 한 사람, B는 못 한 감정 표현 |
| 33 | (전문가 A)의 폭로, 90%가 당하는 (사기 방법 B) | 사람들이 많이 하는 행동이어야 함 |
| 34 | (몸의 통증/문제 A) 가장 위험한 신호는 '이 증상'입니다 | 가장 걱정하는 문제, 신체적 위협 |
| 35 | 비싼 돈 내고 했던 (A)의 비극 "(피해 대사)" | |

## 실전 워크플로우 예시 (시트 12행: 영어공부 → 초등 고전 독서)

1. 벤치마크: 문구 "영어 문장 한글처럼 읽는 법" / 제목 "이 방법으로 읽으니 영어 문장 다 뚫렸습니다." (140만 조회)
2. 1단계: 상황=영어 책 읽기·영어 공부 잘하고 싶은 마음 / 고민=한글처럼 잘 읽을 수 없을까 /
   욕구=영어 실력 향상 / 계획=영어 책 잘 읽는 방법 알고 싶다
3. 2단계: 문구 기대 9 + 그림 기대 1 (영어 책 손가락으로 가리키며 읽는 모습)
4. 3단계: (내가 원하는 것 A)을 (평소에 쉽게 하는 것 B)처럼 하는 방법 ("이 방법으로 하니 A를 다 해결했습니다.")
5. 4단계: A=초등 고전 독서 → "초등 고전 독서를 만화책처럼 읽는 방법"
   ("이 방법으로 하니 초등 고전 독서, 완전 푹! 빠지게 만듭니다.") + 변주 다수.
   이미지: 그림 기대 1 → 유명 고전(데미안·싯다르타·인간관계론)을 들고 편안하게 읽는 아이 사진으로 기대 상승.
6. 5단계: 학부모가 "방법"을 원하는 다른 키워드 확장 → 4단계 반복
7. 6단계: 상황-고민-욕구-계획 연결·욕구 강도 점수화 (외부 리서치로 확인)

# 썸네일 파이프라인 — 구글 시트 직접 읽기/쓰기 설정 (1회, 약 10분)

파이프라인이 벤치마킹 시트를 직접 읽고 결과를 써넣으려면 **구글 서비스 계정** 1개가 필요하다.
(개인 구글 로그인은 GitHub Actions에서 쓸 수 없어서, 시트 전용 로봇 계정을 만드는 방식)

## 1. 서비스 계정 만들기

1. https://console.cloud.google.com 접속 → 프로젝트 선택(없으면 새 프로젝트, 이름 아무거나 예: `dreamgrow`)
2. 왼쪽 메뉴 **API 및 서비스 → 라이브러리** → "Google Sheets API" 검색 → **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → 서비스 계정**
   - 이름: `dreamgrow-thumbnail` (아무거나) → 만들기 → 역할은 건너뛰어도 됨 → 완료
4. 만든 서비스 계정 클릭 → **키** 탭 → **키 추가 → 새 키 만들기 → JSON** → 다운로드
   (`xxxx.json` 파일이 받아진다 — 이 파일이 비밀번호다. 아무 데도 올리지 말 것)

## 2. 시트를 서비스 계정에 공유

1. 다운받은 JSON 안의 `"client_email"` 값을 복사 (예: `dreamgrow-thumbnail@프로젝트.iam.gserviceaccount.com`)
2. 벤치마킹 스프레드시트 열기 → 우상단 **공유** → 그 이메일을 붙여넣고 **편집자**로 공유

## 3. GitHub Secret 등록

1. `dream0grow/dream-grow-content-automation` → Settings → Secrets and variables → Actions
2. **New repository secret**
   - Name: `GSHEET_SA_JSON`
   - Value: 다운받은 JSON 파일 내용 **전체를 그대로** 붙여넣기

## 4. 끝 — 동작 방식

- `thumbnail.yml`이 2시간마다 시트 분석 탭을 폴링한다. 수동 실행(Run workflow, topic 비움)도 가능.
- **처리 조건**: 행에 `내가 만들 영상 키워드`(K열)가 적혀 있고 `문구 디벨롭`(N열)이 비어 있으면 처리.
  (벤치마킹 영상 URL(B열) 또는 제목(D열) 중 하나는 있어야 한다)
- 벤치마킹 썸네일은 영상 URL로 이미지를 받아 **비전 OCR**로 문구·그림을 읽는다.
- 결과는 같은 행의 **빈 칸에만** 써넣는다 (사람이 이미 쓴 칸은 절대 덮지 않음):
  상황/고민/욕구/계획(E~H), 썸네일 문구 감정(I), 그림 감정(J), 문구 디벨롭(N, 구조분석+변주+검증),
  이미지 디벨롭(O), 만든 제목(Q).
- 5단계 확장 키워드는 벤치마크 행 바로 아래에 새 행으로 삽입되고 행 그룹으로 묶인다
  (L열=새 키워드, M열=문구 디벨롭).
- **썸네일 이미지 렌더 (색칠 = 확인 완료 신호)**: `이미지 디벨롭`(Q)과 `만든 제목`(S) 두 칸에
  **배경색을 칠하면** 수정·확인 완료로 보고, 다음 실행에서 그 행의 확정 문구·이미지 지시로
  1280×720 썸네일을 렌더한다. 결과는 `만든 썸네일`(R)에 링크 기록 + 볼트
  `파이프라인/썸네일/` 저장(PNG/JPG) + 텔레그램으로 이미지 전송. R이 채워진 행은 다시 안 만든다
  (다시 만들려면 R을 비우면 된다). 렌더가 끝나면 파이프라인이 Q·S를 **파란색**으로 바꾼다
  — 노랑 = 사람 컨펌 완료, 파랑 = 작업(렌더) 완료.
- S열 형식: 첫 줄(들)=썸네일 문구, 마지막에 괄호로 영상 제목. 예)
  `고전을 만화책처럼 읽는 법` ⏎ `(이 방법으로 읽으니 아이가 고전을 다 읽었습니다)`
- 렌더된 1280×720 PNG/JPG는 Actions 아티팩트, 기획 md는 볼트 `05 리뷰/대기`(텔레그램 알림·답장 핑퐁).

## 시트/탭을 바꾸고 싶으면

- 다른 스프레드시트: 시크릿/환경변수 `DG_THUMB_SHEET_ID`
- 다른 탭: `DG_THUMB_SHEET_GID` (탭 URL의 `gid=` 숫자)
- 열 배치를 바꾸면 `orchestrator/thumbnail.py`의 `COL` 표를 함께 수정

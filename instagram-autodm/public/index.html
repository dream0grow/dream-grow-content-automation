사용 설명

      

        
작동 흐름

        
    
          
  1. 댓글 감지 — 게시물/릴스에 키워드 댓글이 달리면 Meta 웹훅이 서버로 알림을 보냅니다.
    2. 
          
  2. 자동 대댓글 — 243개 문구 풀에서 무작위로 골라 @아이디를 붙여 지연 시간 후 게시합니다.
    3. 
          
  3. 버튼형 DM (Private Reply) — 이미지·제목·부제목·버튼이 있는 카드 DM을 보냅니다. 팔로워면 받은 메시지함, 비팔로워면 '요청' 폴더에 도착합니다.
    4. 
          
  4. ★ 팔로우 확인 — 사용자가 버튼을 누르면 Instagram User Profile API 의 is_user_follow_business 값을 조회합니다.
    5. 
          
  5. 분기 — 팔로워면 버튼 속 메시지(리드마그넷 링크)를 즉시 전송, 비팔로워면 안내 메시지 + 팔로우했어요. 재시도 버튼을 보냅니다. 팔로우 후 재시도하면 통과합니다.
    6. 
        

        
인스타그램 규칙 (중요)

        
    
          
  • Private Reply 는 댓글당 1회, 댓글 작성 후 7일 이내에만 보낼 수 있습니다.
    • 
          
  • 이후 메시지는 사용자가 응답(버튼 클릭 포함)한 뒤 24시간 안에만 보낼 수 있습니다. 그래서 '버튼 → 확인 → 공개' 구조가 필요합니다.
    • 
          
  • 자동 대댓글이 너무 잦으면 제재 위험이 있습니다. 지연 300초 이상, 게시물별 시간당 4개 이하를 권장합니다. 오류가 반복되면 자동으로 대댓글을 멈춥니다(자동 DM 은 계속).
    • 
          
  • 인스타그램 앱 설정 → 메시지 → 메시지 요청 → '메시지 접근 허용' 이 꺼져 있으면 DM 이 가지 않습니다.
    • 
        

        
치환자

    • 
          
  • [today] [tomorrow] [1week] [2weeks] 날짜 자동 계산

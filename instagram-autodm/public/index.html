사용 설명

      

        
작동 흐름

        
    
          
  1. 댓글 감지 — 게시물/릴스에 키워드 댓글이 달리면 Meta 웹훅이 서버로 알림을 보냅니다.
    2. 
          
  2. 자동 대댓글 — 243개 문구 풀에서 무작위로 골라 @아이디를 붙여 지연 시간 후 게시합니다.
    3. 
          
  3. 버튼형 DM (Private Reply) — 이미지·제목·부제목·버튼이 있는 카드 DM을 보냅니다. 팔로워면 받은 메시지함, 비팔로워면 '요청' 폴더에 도착합니다.
    4. 
          
  4. ★ 팔로우 확인 — 사용자가 버튼을 누르면 Instagram User Profile API 의 is_user_follow_business 값을 조회합니다.
    5. 
          
  5. 분기 — 팔로워면 버튼 속 메시지(리드마그넷 링크)를 즉시 전송, 비팔로워면 안내 메시지 + 팔로우했어요. 재시도 버튼을 보냅니다. 팔로우 후 재시도하면 통과합니다.
    6. 
        

        
인스타그램 규칙 (중요)

        
    
          
  • Private Reply 는 댓글당 1회, 댓글 작성 후 7일 이내에만 보낼 수 있습니다.
    • 
          
  • 이후 메시지는 사용자가 응답(버튼 클릭 포함)한 뒤 24시간 안에만 보낼 수 있습니다. 그래서 '버튼 → 확인 → 공개' 구조가 필요합니다.
    • 
          
  • 자동 대댓글이 너무 잦으면 제재 위험이 있습니다. 지연 300초 이상, 게시물별 시간당 4개 이하를 권장합니다. 오류가 반복되면 자동으로 대댓글을 멈춥니다(자동 DM 은 계속).
    • 
          
  • 인스타그램 앱 설정 → 메시지 → 메시지 요청 → '메시지 접근 허용' 이 꺼져 있으면 DM 이 가지 않습니다.
    • 
        

        
치환자

        
    
          
  • [username] 이름(없으면 아이디) · @[username] 아이디 멘션(대댓글용)
    • 
          
  • [today] [tomorrow] [1week] [2weeks] 날짜 자동 계산
    • 
        


        
🎬 릴스에 자동화 걸기

        
    
          
  • 자동화 편집 화면의 적용 대상에서 🎬 릴스만을 고르면 지금 있는 릴스와 앞으로 올릴 새 릴스 전부에 자동 적용됩니다.
    • 
          
  • 특정 릴스만 고르고 싶으면 직접 선택 → 목록 위 🎬 릴스 필터를 누르세요. 측션 검색도 됩니다.
    • 
          
  • 목록은 최근 게시물 300개까지 불러옵니다. 방금 올린 릴스가 안 보이면 새로고침을 누르세요.
    • 
          
  • 스토리는 댓글이 없어서 게시물 목록에 나오지 않습니다. 대신 설정의 스토리 멘션 자동 DM 을 쓰세요.
    • 
        


        
⏰ 예약 발송 · 🎠 캐러셀 · 📣 단체 DM

        
    
          
  • 예약 발송 — 런칭·공동구매처럼 "알림 신청" 댓글을 미리 받아두고, 정해둔 시각에 DM 을 일괄 발송합니다. 대댓글은 댓글이 달릴 때 바로 달립니다. 댓글 시점으로부터 7일 이내여야 합니다.
    • 
          
  • 캐러셀 — 버튼형 DM 에 카드를 더 붙이면 옆으로 넘기는 카드 묶음이 됩니다 (최대 10장, 카드당 버튼 3개).
    • 
          
  • 단체 DM — 인스타그램 규칙상 최근 24시간 안에 반응한 사람에게만 보낼 수 있습니다. 남은 시간이 표시됩니다.
    • 
          
  • DM 첫화면/고정메뉴 — 첫화면은 최대 4개, 고정 메뉴는 최대 5개까지 인스타그램에 직접 저장됩니다.
    • 
        


        
🛡️ 제재 경고 단계적 대응

        
    
          
  • 대댓글 오류 1·2차 → 경고 기록 + 대댓글 간격을 자동으로 늘립니다.
    • 
          
  • 3차 → 자동 대댓글을 즉시 중단합니다. 자동 DM 은 계속 작동합니다. 5~7일 뒤에 다시 켜주세요.
    • 
          
  • 대시보드의 자동 DM 진단 카드에서 흔한 원인을 한번에 점검할 수 있습니다.

# 예시 — B 보완 모드: 「학습지 1장을 30분 동안 붙잡고 있는 아이」

## 사용자가 붙인 초안 (원문 그대로)

```
1. 학습지 1장을 30분동안 붙잡고 있는 아이의 문제점
학습지 한 장을 30분동안 풀면, 다들 '집중력이 없나' 싶죠. 그런데 여기서 '집중력'을 보면 안돼요.
초등학생의 학습 동기, 집중력은 처음부터 생기지 않아요. 하고 싶지 않은 게 당연합니다.
그냥 하게 만들어야 해요.
```

판정: 후킹·공감·원리는 있고, **교실 장면·실천법(부모 대사)·마무리**가 비어 있다.
사용자 어미는 "~죠 / ~해요 / ~합니다" 혼용 → 덧붙이는 문장도 같은 어미로.
사용자 원문이 118자이므로 덧붙일 예산은 약 170자(합계 300자 안팎, 47초).

## 표시본 (무엇을 손댔는지)

```

[추가] 그래서 양부터 줄이세요. 한 장 말고 다섯 문제. 끝이 보여야 손이 움직입니다.
[추가] 끝나면 한마디. "오늘 다섯 문제 딱 채웠네." 해냈다는 걸 짚어주는 거예요.
[추가] 집중력은 앉혀서 만드는 게 아니라, 짧게 끝내 본 경험이 쌓여서 생깁니다.
```

맞춤법만 고친 곳: "30분동안"→"30분 동안", "안돼요"→"안 돼요". 의미·표현·순서는 그대로.
실천법을 세 개 쓰면 60초를 넘겨서(1차 초안 428자=66초) **양 줄이기 하나**로 좁혔다. 한 편에 메시지 하나.

## 낭독 시간 계산 (실측 기준)

낭독 글자 수(제목·화면 지시 제외, 공백 포함) ÷ 6.5 = 초. 쇼츠 낭독은 분당 약 390자다.
```bash
python3 - <<'PY'
text = open("최종본.txt", encoding="utf-8").read()
n = len(text.replace("\n", " ").strip())
print(f"{n}자 → 약 {n/6.5:.0f}초")
PY
```
주의: 볼트의 기존 릴스 원고는 낭독 600자 안팎인데 "약 42초"로 적혀 있다. 실제로는 90초 가까이 되므로
그 표기를 길이 기준으로 삼지 않는다. 새 대본은 260~325자(40~50초)를 목표로 하고 390자(60초)를 넘기지 않는다.
